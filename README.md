# guess-the-word-main
🕹️ Guess the Word Game
A fun, interactive word-guessing game built as part of the Skillcrush JavaScript Web Development curriculum. This project focuses on DOM manipulation, fetching data from an external API, and managing game state.

🚀 How to Play
The game selects a random word from a library.

Guess one letter at a time to uncover the hidden word.

You have a limited number of guesses—make them count!

Win the game by correctly identifying all the letters before you run out of turns.

🛠️ Features
Dynamic Word Selection: Fetches a list of words from a text file/API to ensure a new challenge every game.

Real-time Validation: Checks for duplicate guesses and non-alphabetical characters.

Responsive UI: Updates the "letters guessed" list and remaining count instantly.

Game Loop: Provides a "Play Again" button to restart without refreshing the page.

💻 Tech Stack
HTML5 for structure.

CSS3 for custom styling and layout.

JavaScript (ES6+) for game logic, event listeners, and asynchronous programming.

📖 What I Learned
Through this Skillcrush project, I strengthened my understanding of:

Using async/await to fetch and parse data.

Manipulating the DOM to update elements dynamically based on user input.

Working with arrays and string methods to track and validate guesses.
